# Veyora Labs — Digital Engineering Studio

Original fictional IT company website built with React, Vite, JavaScript, React Router, Tailwind CSS, Framer Motion, and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Routes

- `/` — Home
- `/about` — About
- `/services` — Services overview
- `/services/:slug` — Service detail
- `/work` — Concept portfolio
- `/work/:slug` — Concept case study
- `/process` — Process
- `/technology` — Technology
- `/insights` — Editorial insights
- `/careers` — Careers information
- `/contact` — Contact form demo
- `/privacy-policy` — Privacy template
- `/terms` — Terms template
- Any unknown URL — Custom 404

## Important notes

Veyora Labs and the portfolio entries are fictional concepts. No client work, testimonials, business statistics, or real outcomes are claimed. The contact form currently validates input in the browser only; it does not send or store submissions. Configure a backend/form provider before using it in production.

This is an original design direction inspired by the breadth of the supplied reference brief. The reference site's full route inventory was not verified, so this project should not be treated as a route-for-route recreation.
